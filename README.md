# Predictive Maintenance AI — Actividad 5

**Gestión de Proyectos de Inteligencia Artificial | Módulo 2, semana 6**

> **Estado:** proyecto en preparación. Las métricas y las capturas de MLflow se publicarán **solo después** de ejecutar el entrenamiento y verificar los resultados reales.

## Objetivo
Preparar y versionar el dataset público **AI4I 2020 (UCI)**, comparar **regresión logística** y **random forest** mediante `GridSearchCV` con validación cruzada estratificada, y registrar hiperparámetros, métricas, modelos y artefactos en **MLflow Tracking**.

- Dataset: [UCI AI4I 2020](https://doi.org/10.24432/C5HS5C), sintético, CC BY 4.0.
- Problema: **clasificación binaria de fallas presentes**, sin afirmación de anticipación temporal.
- Entorno principal: Windows, Python 3.13.5, MLflow 3.17.1 en `http://127.0.0.1:5000`.
- Entregable: repositorio GitHub y reporte PDF, sin ZIP obligatorio.

## Ética y metodología

El conjunto es sintético y altamente desbalanceado. Se usará exclusivamente entrenamiento para transformar datos y ajustar hiperparámetros con validación cruzada. Se conservará un conjunto de prueba separado para evaluación final, sin escoger configuraciones mirando el resultado de prueba. Todo costo económico será hipotético salvo que exista evidencia documental.
